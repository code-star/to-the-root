An introduction to generative art in p5.js

by
Dennis van Oosten

If you like coding as much as being creative, generative art might just be the perfect hobby for you.

#JavaScript
#Tutorial
#p5.js
#Creative coding
#Generative art

Share

Generative art can be defined as art that has been generated by an algorithm. The algorithm has a set of defined rules, but is also random in nature, which results in a different output - and thus a different piece of art - each time the program runs.

Creating a generative art algortithm is often a case of adding rules and tweaking parameters. You can start out simple and add more complexity over time. Every time you re-run the program surprising results may occur. This fast experimentation results in a fun and satisfying creative process.

What we’ll be doing

In this tutorial, I’d like to make you familiar with the basic concept of creating generative art. We won’t dive into complex topics, but we will go through the process of creating a piece of art from start to finish.

First, we’ll setup a local environment using the p5.js library. This JavaScript library was designed especially for creative coding and provides all the tools you need to start experimenting. It has some very useful features for randomization and provides very simple ways to draw shapes.

Next, we’ll create a generative algorithm that creates different looking planets, based on a set of simple rules. All we’re really going to do is draw circles and lines, but the outputs can already get quite complex, making use of for-loops and randomization.

Github

The complete code for this tutorial can be found on my github page: Generative Planets.

Setting up a local environment

You can use p5.js in different ways. You can get started with the web editor, which requires no setup, but we’ll be setting up a local development environment in Visual Studio Code.

Live Server

First things first: in order to easily run sketches on a localhost, I’ve installed the Live Server extension by Ritwick Dey in Visual Studio Code. It adds a button to the bottom right of your window to instantly launch a localhost.

p5.js

We’ll need to download the p5.js library in order to work with it. Download the p5.min.js file from the p5.js download page. It’s under the Single files section. The file contains minified code of the p5.js library. If you prefer the larger, but more readable code, you can download the full, uncompressed version as well. Create a new project folder and add the file to it.

Next, create an HTML file in the same folder, index.html:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>Generative Planets</title>

    <link rel="stylesheet" type="text/css" href="style.css">

    <script src="p5.min.js"></script>
  </head>

  <body>
    <script src="sketch.js"></script>
  </body>
</html>

This is a basic HTML file with a title and a link to a stylesheet we’ll create in the next step. Also note we’re referring to the p5.min.js script. Lastly, there is a reference to sketch.js in the body. This is the script for our actual sketch. We will also create this in a later step.

Create a CSS file, style.css:

html, body {
  margin: 0;
  padding: 0;
  background-color: #1b1b1b;
}

canvas {
  display: block;
}

I’ve set a gray background color because I like working on a dark background. This has nothing to do with the background of our sketch, just with the color of the browser’s background.

Lastly, create a JavaScript file, sketch.js:

function setup() {
    createCanvas(900, 900);
}

function draw() {
    background(220);
}

The file contains two p5.js methods. These are the two standard p5.js methods you’ll find at the start of every p5.js tutorial. setup() will be called once when the sketch is initialized. We create a canvas in here with a width and height of 900. draw() is called every frame. We can draw shapes here to animate a sketch if wanted to. We’ll just produce a still image in this tutorial, so we don’t really need this method.

The default color mode in p5.js is RGB, 255, which means colors are defined by values between 0 and 255 using the RGB color model. Setting the background to 220 is equivalent to background(220, 220, 220), resulting in a very light (almost white) gray.

If you run the sketch now using Live Server, you should see a white square. We’ve got a blank canvas to work with!

Creating a generative algorithm

In order to create a more reusable setup, replace the contents of sketch.js with the following:

const canvasW = 900;
const canvasH = 900;

let midX;
let midY;

function setup() {
    midX = canvasW / 2;
    midY = canvasH / 2;

    let canvas = createCanvas(canvasH, canvasH);

    canvas.position(
        window.innerWidth / 2 - midX,
        window.innerHeight / 2 - midY
    );

    background(0);
}

I extracted the width and height of the canvas into separate variables. For later convenience midX and midY represent the center of the canvas. canvas.position() uses these values, along with the window size to position the canvas in the center of the screen. Lastly, I’ve removed the draw() method and set the background color inside the setup method. I’ve chosen black instead of white for our cosmic background.

To the stars and beyond

Now that we’re all setup, let’s draw some shapes! We’ll create stars by drawing little dots (circles). Create a new method, createStars():

function createStars() {
    noStroke();
    fill(255);
    ellipse(midX, midY, 100, 100);
}

When we draw shapes in p5.js, there are three basic settings we can change to alter the appearance of our shapes:

  • stroke color: using stroke(color) or noStroke()
  • stroke weight: using strokeWeight(weight)
  • fill color: using fill(color) or noFill()

noStroke() and noFill() take no arguments. They just remove the stroke and fill respectively.

stroke(color) and fill(color) set the color of the stroke and fill of the shape respectively. You can provide a few numbers here to specify the desired color, just like we did by setting the background.

strokeWeight(weight) expects a number that specifies the weight of the stroke in units of pixels.

When you set either of these properties, its values are used until you change them. Because we’re going to draw many shapes and we’re not sure in what order we’ll draw them beforehand, it is good practice to define the stroke and fill you would like for your shape just before you draw it. I this case, we’re removing the stroke and setting the fill to white.

Drawing a circle is done with the ellipse function. This circle is drawn in the middle of the screen (0, 0) is the top left in p5.js an (canvasW, canvasH) is the bottom right. The size of the circle is set by defining it’s width and height. In our case both 100 to form a perfect circle.

If you run your sketch now (just save it and Live Server will refresh the page), you should see a white dot in the middle of the screen.

We don’t want just one big star however, but rather a whole background filled with them. Therefore, add a for loop to add one hundrerd stars:

function createStars() {
    noStroke();
    fill(255);
    
    for (let s = 0; s < 100; s++) {
        ellipse(midX, midY, 100, 100);
    }
}

Adding a generative element

Right now, we’re drawing one hundrerd stars on the canvas, but they’re all in the same position and of the same size. Furthermore, every time we refresh the page, the output is the same. In order to get a generative artwork, we want to create an algorithm that generates different outputs. To accomplish this, we’ll add some randomness to the creation of stars:

function createStars() {
    noStroke();
    fill(255);

    for (let s = 0; s < 100; s++) {
          let x = random(0, canvasW);
          let y = random(0, canvasH);
          let size = random(1, 3);

          ellipse(x, y, size, size);
    }
}

Instead of setting the position to the middle of the screen, we generate a random x- and y position for each star. p5.js has a handy random() function. Just calling this without any parameters generates a random number between 0 and 1. For the x postion, we want a random number between 0 (left side of the canvas) and the canvas’s width (right side of the canvas). For the y position, we want a number between 0 (top of the canvas) and the canvas’s height (bottom of the canvas). I set the size to be a random number between 1 and 3, but the fun thing of generative art is that you can easily tweak the numbers and generate multiple outputs until you’re happy with the look. A slightly different number sometimes generates vastly different outputs.

Call the function at the end of setup():

createStars();

If you run the sketch again, your background should be full of twinkling stars. Every time you save or refresh, the starfield changes.

The birth of a planet

Create a new method to generate a planet:

function createPlanet(x, y, width, height) {
    fill(255);
    stroke(255);
    strokeWeight(width / 20);
    ellipse(x, y, width, height);
}

The function takes four parameters that define the position and size of the planet.

The fill and stroke are set to white and the strokeWeight is set relative to the width of the planet. We use an ellipse again to draw the shape of the planet.

Call the function at the end of setup():

const planetWidth = 500;
const planetHeight = 500;

createPlanet(midX, midY, planetWidth, planetHeight);

If you save the sketch, you should see an empty, white planet.

Next, we’ll create different types of planets with random patterns.

Stripes

Create a new function that draws a bunch of stripes:

function createStripes(x, y, width, height) {
    for (let h = 0; h < height; h += 20) {
        let stripeY = h + y - height / 2;
        let stripeHeight = 10;

        stroke(0);
        strokeWeight(stripeHeight);
        noFill();
        line(x - width / 2, stripeY, x + width / 2, stripeY);
    }
}

This function creates a stripe of 10 points high, with an interval of 20 points across the height of the planet.

The stroke is set to black and the fill is removed.

Drawing a line in p5.js is done by setting the x- and y values of the first point, followed by the x- and y values of the second point.

Now to add some randomness to the stripe pattern, add a few random values at the top of the function:

let minStripeHeight = random(1, 30);
let maxStripeHeight = minStripeHeight + 30;
let stripeChance = random(0.2, 0.8);

And replace the contents of the for-loop with the following:

if (random() < stripeChance) {
    let stripeY = h + y - height / 2;
    let stripeHeight = random(minStripeHeight, maxStripeHeight);

    stroke(0);
    strokeWeight(stripeHeight);
    noFill();
    line(x - width / 2, stripeY, x + width / 2, stripeY);
}

We’re using the stripe height values to create a new random stripe height for each of the stripes in the for-loop. We use the stripe chance to determine wheter a stripe should be drawn or not.

Notice that we essentially have two layers of randomness in this funtion. The minStripeheight, maxStripeHeight and stripeChance are set once for the stripe pattern, whereas the actual stripeHeight and whether a stripe is drawn or not are determined for each individual stripe (each iteration of the for loop). Doing so ensures we have consistency between stripes, but get different patterns for different planets.

Call the method at the end of createPlanet():

createStripes(x, y, width, height);

The stripes are drawn on top of the planet. In order to clip them to the shape of the planet, add the following two lines before the call to createStripes():

drawingContext.save();
drawingContext.clip();

And this one after the call to createStripes():

drawingContext.restore();

If you run the sketch again, you should see a planet with stripes that only occur on the planet’s surface.

Spots

In addition to stripy planets, let’s create spotty planets as well. Create a new function:

function createSpots(x, y, width, height) {
  for (let h = 0; h < height; h += height / 30) {
    if (random() < 0.33) {
      let spotX = random(x - width / 2, x + width / 2);
      let spotY = h + y - height / 2;
      let spotColor = random(0, 1) < 0.5 ? 0 : 255;
      let spotSize = random(5, 50);

      noStroke();
      fill(spotColor);
      ellipse(spotX, spotY, spotSize, spotSize);
    }
  }
}

This function takes the same parameters for position and size again. It also contains a loop that creates multiple spots.

For every iteration of the loop, the chances for a spot are roughly 1/3. For each spot, a random x position is chosen and the y position is set based on the current iteration.

The color of a spot is either black or white, with a 50/50 chance for both colors.

The size of the spot is also random and varies between 5 and 50.

Lastly, we remove any stroke and set the fill color to the random spot color. We draw the spot using the ellipse() function again, using the random x position, y position and spot size.

In createPlanet() replace the call to createStripes() with the following:

let planetType = random();
  
if (planetType < 0.5) {
    createStripes(x, y, width, height);
} else {
    createSpots(x, y, width, height);
}

Run the sketch again. Every time the sketch is refreshed and a new planet is created, it will be either a stripy or a spotty planet.

We can mix this up some more. Change the above code to the following:

let planetType = random();

if (planetType < 0.4) {
    createStripes(x, y, width, height);
} else if (planetType < 0.8) {
    createStripes(x, y, width, height);
    createSpots(x, y, width, height);
} else {
    createSpots(x, y, width, height);
}

Now we have a 40% chance of creating a stripy planet, a 20% chance of creating a spotty planet and a 40% chance of creating a planet that has both stripes and spots!

Creating a planetary system

To make out artwork just a little more interesting, we’re going to display multiple planets at once. Replace the end of setup():

const planetWidth = 500;
const planetHeight = 500;

createPlanet(midX, midY, planetWidth, planetHeight);

with the following:

const nrPlanets = 5

for (let p = 0; p < nrPlanets; p++) {
    let separation = (canvasW - 750) / (nrPlanets - 1);
    let posX = separation * p + 375;
    let size = random(75, 400);

    createPlanet(posX, midY, size, size);
}

We’re creating 5 planets.

In the for-loop, we calculate the separation (space between planets) by taking the canvas width, subtracting a margin and dividing it by the number of planets - 1. The x position is calculated by taking the separation and multipling it by the planet index p, as well as adding half of the margin. This ensures we center the planets nicely onto the canvast, no matter how many planets we create.

The size of a planet is randomized between 75 and 400.

Change the size of the canvas to accomodate for our row of planets:

const canvasW = 2500;
const canvasH = 1000;

If you run the sketch now, you might notice that the stripes and spots are scaled up. This is because we’re drawing them at the same size, even though our planet’s width and height are now smaller. Let’s make the scale of the stripes and spots dependant on the size of the planet.

In createStripes(), change the minStripeHeight and maxStripeHeight to the following:

let minStripeHeight = random(1, height / 50);
let maxStripeHeight = minStripeHeight + height / 10;

They are now both dependant on the height of the planet: a smaller planet will result in a smaller min and max stripe height.

Inside createSpots(), change the spotSize to:

let spotSize = random(height / 50, height / 5);

This will make the size of the spots dependant on the height of the planet as well.

Lastly, let’s make the stars in the background a little bigger, since increasing the canvas’s size made them almost disappear.

Inside createStars(), change the line that sets the size to:

let size = random(2, 5);

Also increase the star count to 200 by adjusting the for-loop:

for (let s = 0; s < 200; s++) {
    ...
}

If you run the sketch again, smaller planets should have smaller stripes and spots and the stars in our cosmic background should be more prominent.

Conclusion

Hopefully you can’t wait to start experimenting yourself. As you’ve seen, combining functions, for-loops and randomized variables can lead to a lot of variation with very little code.

p5.js is a great tool for creative coding and makes experimenting simple and fun. It has a lot more to offer though. This was just the tip of the iceberg!

Where to go from here

We’ve covered the basics of generative art, but there is lots more to explore. Using noise for example instead of a random number, or working with polar coordinates. Adding nice colors can be quite challenging. And what about saving or animating your artworks?

I might turn this article into the first entry of a new series, so stay tuned on To The Root.

For now, there are lots of great resources online. One of them is The coding train. Its YouTube channel has many video’s on p5.js. It also covers more complex topics and offers a lot of content on algorithms that will spark your creativity. Happy coding!
