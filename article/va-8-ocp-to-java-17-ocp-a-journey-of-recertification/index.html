From Java 8 OCP to Java 17 OCP: A Journey of Recertification

by
Laurens van der Kooi

In fall 2021 Oracle announced the new Java 17 1Z0-829 Certification exam. Passing this exam earns you the Oracle Certified Professional (OCP) status for Java 17 SE, which is the current Long Term Support (LTS) version of Java.

Since I got my OCP certification for Java 8 SE back in 2019, having worked extensively with Java 11 and 17, I was curious to find out if it is worth the effort to become certified for newer Java versions as well. In this article based on personal experience, I'll describe my takeaways from getting recertified for a new Java version as an experienced, OCP certified Java developer. I will mention books and other products in this article. However, it is important to clarify that I have no affiliation with the companies responsible for publishing, producing, or selling these items.

The new Oracle Certification path
One of the things that sparked my curiosity was the change Oracle made to the Java certification path starting with the Java 11 certification in 2020. A notable distinction between the (pre) Java 8 and the newer certification paths is the structure of the certification process. Previously, you would follow a two-step approach to become an OCP. First, you would study and pass an exam to become an Oracle Certified Associate (OCA). Upon achieving the OCA certification, you had the option to prepare for the next exam and become an OCP as well. 

As per the Java 11 certification path, there is no OCA certification anymore and you immediately prepare for the OCP certification (see image 1). This means that you only need to take and pass one exam instead of two. This change also entails a significant increase in the study load to pass the exam since the number of topics that were previously covered in two separate exams are now consolidated into a single exam.


Image 1: the different Java SE certification paths Oracle currently provides (source: Oracle University)

Fun fact: The Java 11 certification path initially included a temporary upgrade exam, specifically designed for candidates who were already OCP certified. However, the upgrade exam for Java 11 is no longer available as of December 2021. Interestingly, the Java 17 certification path does not offer an upgrade exam at all. In my situation, this meant that I had to thoroughly prepare for all the topics covered in the Java 17 certification path.

Differences between Java 8 OCP and Java 17 OCP
When I began my preparation for the Java 17 exam, I decided to compare the topics covered in the Java 8 OCA and OCP exams with those of the Java 17 OCP exam. Surprisingly, I found that there aren't many differences between the exam topics of the Java 8 exams and the Java 17 exam.

New topics naturally focus on the additional features introduced in Java 11 and Java 17:

  • Declaring local variables with the var keyword
  • Text blocks
  • The Switch expression
  • Records
  • Sealed classes
  • Pattern matching
  • Modules

Furthermore, the objectives of the Java 17 exam also encompass the more subtle changes and additions that have been made to the Java programming language since Java 8. Among them are:

  • Methods added to the String class that can be utilized with text blocks
  • Enhancements to the Stream API
  • The introduction of non-static private methods in interfaces

In addition to the new features introduced in Java 11 and Java 17, the Java 17 exam also covers topics that were not included in the Java 8 exam, despite already being present in Java 8:

  • The Math API
  • Prepared and Callable Statements in the JDBC API

Topics that were part of the Java 8 exam but are not part of the Java 17 exam anymore, include:

  • Using the parallel Fork/Join framework
  • Using assertions
  • Design patterns like singleton and factory

My preparation
In my daily work as a Java developer, I have been actively using Java 11 since 2019 and Java 17 since the start of 2023. Additionally, in my side projects, I have been working with Java 17 since 2021. As a result, I have already gained practical experience with many of the new exam topics and have developed a strong affinity for the new features introduced in Java 17. To avoid the common pitfall of assuming that my experience as a Java developer would be sufficient to excel in the exam with minimal preparation, I made a conscious decision to take a thorough approach. I dedicated myself to reading a comprehensive study guide from cover to cover, delving deeply into the topics introduced after Java 8, as well as revisiting the subjects I had previously studied. This would also allow me to get back into the "thinking as a compiler" mindset that is needed for the exam. Since I still had my notes from the Java 8 OCA and OCP, I decided to update them along the way as I gained new insights or saw things that were different in Java 8. 

For the Java 8 exams I used the study guides written by Scott Selikoff and Jeanne Boyarski. Since I passed those exams on my first attempt using their guides, it was an easy decision for me to purchase their new Java 17 OCP study guide to study for the new certification (see image 2).

 

Image 2: The Java 17 OCP study guide and the Java 8 OCA and Java 8 OCP study guides 

After reading the complete study guide and reviewing my updated notes multiple times, I reached the next phase of my preparation: practicing with mock exams.

Based on my previous experience with Java certifications, I have found Enthuware to be a valuable resource for practice exams. Their software accurately simulates the difficulty level and experience of the real exam. For as little as $10, they supply you with a question bank that contains 20 practice exams and over 1000 practice exam questions. A significant part of the preparation process involves taking these practice exams and reviewing each question after completing them. Enthuware provides each exam question with a detailed explanation of why the correct answer is right and why other answers are wrong. This approach serves as an excellent method to verify that your reasoning on a subject is at a level where you won't easily fall into traps set by the exam creators. Furthermore, taking practice exams is an effective method to familiarize yourself with the required speed for answering the questions. Adequate time management is crucial during the actual exam.

For each practice exam, I dedicated an average of 2 hours. This time was spent on taking the exam, carefully reviewing each question afterward, and updating my notes with any new insights I gained. By completing all the practice exams and examining each question, I felt confident and well-prepared for the actual exam.

The exam
As previously mentioned, to obtain the Java 17 SE OCP certification, one must pass the 1Z0-829 exam. This exam has a duration of 90 minutes, comprises 50 questions, and requires a passing score of 68%.

For the exam, my employer Ordina provided me with an exam voucher. One notable difference compared to the Java 8 OCP exam I took in 2019 is that Oracle exams are no longer administered by Pearson Vue; instead, Oracle itself handles the exam process. In the past, I would schedule an exam with Pearson Vue and take it at a physical location in my hometown. Nowadays, Oracle exams are proctored online and can be booked through the Oracle website. I chose to take this exam from the comfort of my home office.

Oracle provides detailed instructions on how to prepare for the exam day, including the required identification, system test, and test space requirements. The exam is conducted in a browser called LockDown Browser, which restricts access to your operating system and only allows the exam software to be active. During the exam, there are two tabs open in LockDown Browser: one for the exam itself and another for a Zoom session. It is necessary to keep your webcam and microphone on throughout the exam. In case of any issues during the exam, you can communicate with the exam administrator via instant messaging.

Unfortunately, I encountered a technical error in the exam software when I started the exam, preventing me from proceeding. However, after contacting the exam administrator and submitting a support ticket, I was able to reschedule the exam. During my next attempt, I did not encounter any errors, and the exam experience went smoothly without any issues.

The Oracle exam software is similar to the software previously provided by Pearson Vue for Oracle exams. The exam software still provides the option to mark a question, allowing you to easily identify and revisit specific questions during the exam. Moreover, the software continues to offer a clear and visible countdown time.

However, there is one significant difference worth mentioning. In the Pearson Vue exam software, you had the ability to strike out answers by right-clicking on an option. Unfortunately, this feature is no longer available in the Oracle exam software. Personally, I found this feature helpful for questions that I would mark and revisit at the end of the exam. By striking out options, I could easily identify which answers to reconsider without reviewing all of them again. Enthuware, being aware of this change, has also disabled this option in their practice exam software. So, if you are accustomed to using the option to strike out answer choices, like myself, practicing exams with Enthuware allows you to simulate exam conditions without this feature. During the actual exam, you can adopt a strategy where you mark a specific question and review each answer option thoroughly at the end of the exam. This requires good time management during the exam though.

Another notable difference from the Pearson Vue exams is that with the Oracle exams, you receive your score instantly after submitting the exam. In the past, I had to wait for around 30 minutes for my results to become available after leaving the exam location. However, with the Oracle exam, I received instant feedback on my score after submitting the exam. I found this to be a positive change, and it added to my excitement when I saw that I achieved a score of 90%, resulting in my Java 17 SE OCP certification!

Conclusion
So, was it worth the effort to get recertified for Java 17 as a Java 8 OCP? Probably not.

The extensive study load covers subjects already studied intensively for the Java 8 OCA and Java OCP. An upgrade exam focused on new topics would have been a better fit, letting developers get recertified by focusing on new topics that were added to the certifications after Java 8. Unfortunately there is no upgrade exam available in the Java 17 certification path. Therefore, my advice to other Java 8 and Java 11 OCPs out there is to consider finding a good book that specifically discusses the features added to Java after versions 8 and 11. One book I would recommend is "Cruising Along with Java" by Venkat Subramaniam, which covers the features introduced in Java 9 through 19.

For developers certified in a version prior to Java 8, I recommend giving thought to the Java 17 OCP certification. Java 8 brought significant changes and introduced new features that have become the standard in modern Java development. Having a thorough understanding of these features is crucial for staying current in the evolving Java development landscape. By pursuing the Java 17 OCP certification, you can quickly update your knowledge and also become familiar with the exciting additions in Java 11 and 17. It's an opportunity to stay up-to-date and explore the latest advancements in the Java language.

If you haven't pursued a Java OCP certification yet, I highly recommend considering it. Obtaining the certification provides a solid understanding of the Java language, serving as a strong foundation for becoming a skilled Java developer. It's important to take your time preparing for the exam, doing a lot of practice exams and keep in mind that time is limited and you don't have an IDE at hand during the exam. In the end, the feeling of achievement that comes with successfully passing the exam and adding the certification to your CV is truly fulfilling.
