Step 3: Beyond the Local: Your AI Commander Connects to the World 🌎

Now that you've installed the necessary library, it's time to teach your AI how to discover and use tools on remote servers. In this step, your AI becomes a true "AI Commander," capable of delegating specialized tasks.

The function below, get_tools_external_mcp_agent(), configures a MultiServerMCPClient to connect to multiple external MCP servers simultaneously. We'll start by connecting to a variety of External MCP servers, including those for Office Word, Git, Filesystem, and Blender. This demonstrates a key benefit of MCP: you can call tools without needing to manage the underlying infrastructure.

The function get_tools_external_mcp_agent() will:

  • Define the servers to connect to, including commands to launch them on the fly using uv, uvx, and npx. All three let you run tools and MCP servers on the fly without global installation or manual setup.
    • npx (Node.js): Runs JS tools from npm without installing.
    • uv (Python): Fast package and environment manager — like pip + venv combined.
    • uvx (Python): Runs Python tools from PyPI without installing — like npx for Python.
  • Initialize a MultiServerMCPClient to manage these connections.
  • Fetch the available tools from all connected servers.
  • Print a list of the new tools your AI can now use.

With the following code, you're not just adding a new function; you're expanding your AI's capabilities exponentially by giving it access to a growing ecosystem of external services.


Running an MCP server can be done in various ways. The server configuration uses three common methods to execute external tools on the fly:

  • uv and uvx: These are Python-based tools that run a package as a command-line tool on-demand without a permanent install. This keeps the system clean and avoids dependency conflicts. This method is used for the Word and Blender servers.
  • npx: This is the Node.js equivalent of uvx. It runs a Node.js package directly from the npm registry without a local install. The Filesystem server uses npx because it is a Node.js tool.
  • Other Methods (Python and Docker): Servers can also be run using a standard Python environment with a virtual environment. For more complex or production-ready setups, Docker is the preferred method, as it packages the server and its dependencies into a single, portable container that runs consistently anywhere.

Step 5: Examples of New Commands


Now that your AI has access to these new tools, you can use natural language commands to perform complex tasks. Your AI will automatically select the correct tool based on your request.

Using the Office Word tool: You can create and edit documents, add tables, and format content.

  • "Create a Word document named 'Quarterly Report.docx' with the title 'Q2 Report'."
  • "In my 'Quarterly Report.docx' file, add a table with 3 rows and 4 columns and insert the headers 'Product', 'Sales', 'Profit', and 'Loss'."
  • "Format the title of the 'Quarterly Report.docx' document to be bold and centered."

Using the Filesystem tool: You can interact with your local file system as a human would.

  • "List all the files in the mcp-tutorial directory."
  • "Read the content of the instructions_uv_setup.txt file."
  • "Create a new directory named project_files."

Using the Git tool: You can manage your code repository.

  • "Tell me the current status of the git repository."
  • "Commit the changes with the message 'Added new MCP servers'."
  • "Push the changes to the remote repository."


Step 6: Blender MCP server


In this step we explain how to install and integrate the Blender MCP server. This integration enables prompt assisted 3D modeling, scene creation, and manipulation. 

Think of the Blender MCP server as the neural interface between your AI Commander and the vast, complex world of 3D modeling. It's a specialized tool that translates natural language commands into precise actions within Blender, the industry standard for 3D software. This allows you to bypass the steep learning curve of 3D modeling and easily tell your AI what to create.

With this server and a powerful generative tool like Hyper3D Rodin, your AI Commander can:

  • Generate complex 3D models using text prompts. For example, you can instruct it to "create a futuristic car with sleek, curved lines and bright neon accents" and watch the model appear in your Blender scene.
  • Create and modify scenes.
  • Integrate external assets. It can pull high-quality models and materials from other services like Hyper3D Rodin, making the creation process even faster.

Core Lessons Recap

This article teaches you how to transform a single-user AI assistant into an "AI Commander" by enabling it to connect to and use external services. 

The key steps are:

  • Use langchain-mcp-adapters: This library acts as a bridge, allowing your AI to communicate with other servers via the MCP protocol.
  • Define external servers: Configure your AI to connect to specialized MCP servers (such as those for Word, Git, or Blender, Firecrawl) by specifying their run commands.

 

  • Merge tools: Combine your AI's local tools with new external tools, creating a powerful, comprehensive toolkit.

 

  • Connect to the ecosystem: Use MCP marketplaces to find and integrate new servers, continuously adding new capabilities to your AI.


Final Thought

By connecting to external MCP servers, your AI becomes a powerful, extensible commander, capable of delegating specialized tasks and automating complex workflows across an entire ecosystem of services.
